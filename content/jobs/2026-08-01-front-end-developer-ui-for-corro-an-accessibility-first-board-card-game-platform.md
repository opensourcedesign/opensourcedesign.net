Corro is an accessibility-first engine for online board and card games — built so that everyone plays the *same* game together, whatever their abilities. The name evokes a circle of people holding hands as equals, with no head of the table. Accessibility is the foundation of the codebase, not an afterthought. You can try it live at https://allwelcome.games.

I'm the founder, and I'm blind. The engine already treats accessibility as a first-class concern — ARIA live regions for game announcements, full keyboard navigation and focus management, native dialog modals with focus trapping, semantic HTML and server-authoritative announcements. What the front-end needs now is polish: a UI that is as visually refined and pleasant as it is accessible.

**What we're looking for**

A front-end developer to improve and beautify Corro's interface — refining layout, responsiveness and visual detail across the lobby and in-game screens — without breaking the accessibility that is the whole point of the project. You'd work closely with our illustrator/designer to bring the visual layer to life in the browser.

**Tech stack**

- Vanilla TypeScript (no bundler), vanilla CSS
- i18next for localization (English & Spanish today)
- Backend is .NET 10 / ASP.NET Core / SignalR — but this role is front-end focused

**What you'd help with**

- Refining and beautifying the lobby and in-game UI (CSS, layout, responsive/mobile)
- Integrating new artwork and icons into the interface
- Keeping everything keyboard-navigable and screen-reader friendly as the UI evolves
- Small, well-scoped improvements to focus management, live regions and semantic markup

**A good fit if you**

- Are comfortable with modern vanilla TypeScript and CSS (no framework required)
- Take accessibility seriously — or want to get genuinely good at it
- Enjoy careful, detail-oriented UI work
- Are happy contributing to an AGPL-3.0 open-source project

This is a volunteer role. If you want your front-end skills to help build a more inclusive place to play, get in touch.
